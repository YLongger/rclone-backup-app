Privacy Policy

Last updated: 2026-10-05

What this app is

A personal backup setup that uses the open-source tool rclone. It is used only by its owner.

Data accessed

With the signed-in user's permission, the app reads and writes files in that user's own Google Drive, only to upload, list and verify backups. It does not access any other Google data.

Storage and sharing

The sign-in token is stored only on the owner's own computer. No data is collected, sold, shared with third parties, or sent anywhere other than the user's own Google Drive. There is no analytics or advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
